# Business Sales Performance Analytics

## Project Overview
This project analyzes retail sales data using SQL Server Management Studio (SSMS) and Microsoft Excel.

The objective is to identify:
- Revenue trends
- Regional performance
- Product profitability
- Discount impact on profit
- Business recommendations

## Key Insights

- West region generated the highest sales and profit.
- Technology category produced the strongest profit margins.
- Discounts above 20% significantly reduced profitability.
- Texas and Ohio showed major financial losses.
- Furniture category had weak profit margins despite strong sales.

---

## Business Recommendations

- Reduce excessive discounts
- Improve Furniture pricing strategy
- Focus on profitable regions
- Launch promotions during weak Q1 months
- Replicate West region strategy in weaker markets
